# August Miller — Portfolio

Polished single-page portfolio for IS 3060 coursework. This repository contains a clean, responsive landing page for August Miller with sections for About, Skills, Projects (placeholders), Resume (coming soon), and Contact information.

Website

- Project site (if you keep the current repository name): https://AugustMiller06.github.io/August-J-Miller.github.io/
- User site (recommended for a shorter URL): rename the repository to `AugustMiller06.github.io` and publish — then the site will be available at: https://AugustMiller06.github.io

Technologies used

- HTML5 (index.html)
- CSS3 (styles.css)
- Google Fonts (Inter)
- Minimal JavaScript for navigation and small UI behavior

How to publish with GitHub Pages

1. Go to the repository on GitHub.
2. Open Settings → Pages (or Code and automation → Pages).
3. Under "Build and deployment" choose the branch `main` and the folder `/ (root)`, then click Save.
4. Wait 30–60 seconds and GitHub will display the published site URL. If you see a 404 immediately, wait a minute and refresh.

How to customize

- Edit `index.html` to change text, add project links, or adjust content.
- Edit `styles.css` to change colors, spacing, or fonts.
- To add a downloadable resume: upload `resume.pdf` to the repository root and replace the "Resume coming soon" text with:

  `<a href="resume.pdf" download>Download resume (PDF)</a>`

- To preview locally: open `index.html` in your browser, or run a local server (`python -m http.server 8000`) and open `http://localhost:8000`.
